# Demostración: Implementación de EFS

🔗 Parte 1: <https://learn.cantrill.io/courses/3028179/lectures/66797497>
🔗 Parte 2: <https://learn.cantrill.io/courses/3028179/lectures/66797498>

En esta demo se monta un mismo EFS file system en **dos instancias EC2** para compartir las imágenes estáticas de una web store. En la primera instancia se instalan las utilidades de EFS, se agrega el file system a `/etc/fstab` y se monta; después se repite lo mismo en la segunda instancia (copiando la línea de `fstab`) y se descargan los archivos estáticos en el directorio compartido. Como el storage es el mismo, lo que se escribe desde una instancia es visible desde la otra.

### Comandos

```bash
# Install Amazon EFS utilities
sudo dnf install -y amazon-efs-utils

# Edit filesystem table
sudo nano /etc/fstab
# Paste this to a new line:
#   fs-xxxxxxxx:/ /var/www/aem-webstore/static/images efs _netdev,tls 0 0
# Save: CTRL O <enter>   Exit nano: CTRL X

# Mount (using updated fstab)
sudo mount -a

# Check mounts
df -k

# Create test file
sudo touch /var/www/aem-webstore/static/images/test.txt

# Perform the above steps on instance 2
# Copy to instance 2 (ver el contenido de fstab para copiar la línea):
sudo cat /etc/fstab

# Change directory
cd /var/www/aem-webstore/static/images

# Download static files
sudo curl -O https://learn-cloudlee-labs.s3.amazonaws.com/awscoursedemos/efs-webstore/public/aem-webstore-imagefiles.zip

# Unzip the static files
sudo unzip aem-webstore-imagefiles.zip

# Delete the zip
sudo rm aem-webstore-imagefiles.zip
```

### Qué hace cada bloque

| Bloque | Qué pasa |
|---|---|
| `dnf install amazon-efs-utils` | Instala el **helper de montaje de EFS**, que agrega el tipo de file system `efs` y soporte para TLS. |
| Línea en `/etc/fstab` | Declara el montaje de forma persistente: el file system `fs-xxxxxxxx:/` se monta en el directorio de imágenes. `_netdev` espera a que haya red antes de montar y `tls` cifra el tráfico en tránsito. |
| `mount -a` + `df -k` | Monta todo lo declarado en `fstab` y verifica que el EFS aparezca entre los montajes. |
| `touch .../test.txt` | Crea un archivo de prueba: al repetir los pasos en la instancia 2, el archivo tiene que verse ahí también. |
| `cat /etc/fstab` | Muestra la línea para copiarla a la segunda instancia. |
| `curl` + `unzip` + `rm` | Descarga las imágenes de la web store en el directorio **compartido**, así quedan disponibles para ambas instancias. |
