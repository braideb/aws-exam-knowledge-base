# FSx — Key Features and Benefits

> [!note] Resumen de la lección
> Para el examen alcanza con una visión de alto nivel de FSx for Windows: **VSS** (restauraciones hechas por el propio usuario), acceso por **SMB**, **modelo de permisos de Windows** y compatibilidad con **DFS**.

Para el examen no necesitás conocer todos los detalles de implementación; hay funciones de distintos servicios que solo requieren una visión general, y esta es una de ellas. Alcanza con saber algunas cosas.

La primera es **VSS (Volume Shadow Copy Service) user-driven restore**: la feature que permite a los usuarios hacer restauraciones a nivel de archivo y de carpeta sin tener que hablar con un administrador del sistema.

La segunda es que FSx entrega **file systems nativos de Windows accesibles vía SMB**. Recordá que EFS usa el protocolo **NFS**, accesible solo desde instancias EC2 Linux o servidores Linux on-premises.

La tercera es que usa el **modelo de permisos de Windows**: si estás acostumbrado a gestionar permisos de carpetas y archivos en Windows, así es como FSx maneja los permisos.

Por último, es **compatible con DFS (Distributed File System)**, la forma nativa de escalar file systems en entornos Windows: agrupa file shares en una estructura a nivel empresa y sirve para replicación o para aumentar el rendimiento. No suele preguntarse mucho (a lo sumo, una pregunta cada tanto).

> [!tip] Para el examen: palabras clave
> Si la pregunta menciona **SMB**, probablemente la respuesta correcta sea **FSx**. Si menciona **DFS** (por su nombre completo o la sigla), está relacionado con FSx. **NFS** apunta a **EFS**.
