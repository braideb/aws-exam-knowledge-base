# Comparativa: EFS vs FSx for Windows vs FSx for Lustre

> [!note] Resumen de la lección
> Los tres son file systems compartidos y gestionados. Lo que los separa es el **protocolo**, el **sistema operativo** de los clientes y el **caso de uso**, y casi siempre la pregunta del examen trae una palabra clave que delata cuál es.

| Servicio | Protocolo | Sistema operativo | Caso de uso típico | Palabra clave disparadora |
|---|---|---|---|---|
| **EFS** | NFS | Linux (y macOS) | File share compartido para EC2 / Lambda / contenedores | "NFS", "shared Linux file system" |
| **FSx for Windows File Server** | SMB | Windows | File shares nativos de Windows con Active Directory | "SMB", "Windows", "Active Directory", "DFS" |
| **FSx for Lustre** | POSIX (cliente Lustre) | Linux | HPC / machine learning, con datos en S3 | "HPC", "high performance", "machine learning", "Lustre" |

> [!tip] Para el examen
> Linux + compartido → **EFS**. Windows, SMB o Active Directory → **FSx for Windows**. HPC o ML con datos en S3 → **FSx for Lustre**.
