# Demostración: Parameter Store

🔗 <https://learn.cantrill.io/courses/1101194/lectures/27895415>

En esta demo se crean varios parámetros en una **estructura jerárquica**, uno de ellos cifrado (SecureString), y después se leen desde la CLI (por ejemplo, desde CloudShell): de a uno, por rama y con descifrado.

### Parámetros a crear

| Nombre | Valor | Tipo |
|---|---|---|
| `/my-cat-app/dbstring` | `db.allthecats.com:3306` | String |
| `/my-cat-app/dbuser` | `bosscat` | String |
| `/my-cat-app/dbpassword` | `amazingsecretpassword1337` | **SecureString** (cifrado) |
| `/my-dog-app/dbstring` | `db.ifwereallymusthavedogs.com:3306` | String |
| `/rate-my-lizard/dbstring` | `db.thisisprettyrandom.com:3306` | String |

### Comandos

```bash
# GET PARAMETERS (if using CloudShell)
aws ssm get-parameters --names /rate-my-lizard/dbstring
aws ssm get-parameters --names /my-dog-app/dbstring
aws ssm get-parameters --names /my-cat-app/dbstring
aws ssm get-parameters-by-path --path /my-cat-app/
aws ssm get-parameters-by-path --path /my-cat-app/ --with-decryption
```

### Qué hace cada bloque

| Comando | Qué pasa |
|---|---|
| `get-parameters --names <nombre>` | Lee uno o más parámetros **por su nombre completo**. |
| `get-parameters-by-path --path /my-cat-app/` | Lee **toda la rama** `/my-cat-app/` de una vez. El SecureString `dbpassword` se devuelve **cifrado**. |
| `... --with-decryption` | Igual que el anterior, pero **descifra** los SecureString. Requiere permiso sobre la key de KMS. |
