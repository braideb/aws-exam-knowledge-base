# Modelo de responsabilidad compartida (Shared Responsibility Model)

Es útil tener este modelo en mente al estudiar AWS, para saber **qué configura AWS y qué tengo que configurar yo**.

### La división

|Quién|Responsabilidad|Qué incluye|
|---|---|---|
|**AWS**|Seguridad **OF** the cloud (_de_ la nube)|Hardware / AWS Global Infrastructure (Regions, AZs, Edge Locations), Compute, Storage, Database, Networking, y el Software que corre esos servicios.|
|**Customer**|Seguridad **IN** the cloud (_en_ la nube)|Customer data; plataforma, aplicaciones e **IAM**; configuración del SO, red y firewall; encriptación client-side y server-side; protección del tráfico de red.|

> Regla mnemotécnica: **AWS asegura la nube. Vos asegurás lo que ponés dentro de la nube.**

### Modelos de servicio y quién gestiona qué

De más responsabilidad tuya a menos:

|Capa|On-Premises|DC Hosted|IaaS|PaaS|SaaS|
|---|---|---|---|---|---|
|Interface|Vos|Vos|Vos|Vos|**AWS**|
|Application|Vos|Vos|Vos|Vos|**AWS**|
|Data|Vos|Vos|Vos|Vos|**AWS**|
|Runtime|Vos|Vos|Vos|**AWS**|**AWS**|
|Container|Vos|Vos|Vos|**AWS**|**AWS**|
|O/S|Vos|Vos|Vos|**AWS**|**AWS**|
|Hypervisor|Vos|Vos|**AWS**|**AWS**|**AWS**|
|Servers|Vos|Vos|**AWS**|**AWS**|**AWS**|
|Infrastructure|Vos|Vos|**AWS**|**AWS**|**AWS**|
|Facilities|Vos|**AWS**|**AWS**|**AWS**|**AWS**|

Con **IaaS** (ej: **EC2**) la línea de corte está en el **hypervisor**: de ahí para abajo lo maneja AWS, de ahí para arriba lo manejás vos.
