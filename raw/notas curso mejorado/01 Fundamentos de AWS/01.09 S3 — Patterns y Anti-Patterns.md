# S3 — Patterns y Anti-Patterns


S3 es un **object store**. **No** es un _file store_ ni un _block store_. Toda la nota se desprende de esa única frase.

- ❌ **No** se puede montar un bucket de S3 como `K:/` o `/images`. Se guardan objects, no sistemas de archivos.
- ✅ Útil para **offload** de contenido (sacarle carga a los servidores, ej: servir imágenes estáticas).
- ✅ Útil para almacenar el **input y el output** de servicios de AWS (por ejemplo, logs).

**La consecuencia clave**: en un object store **no se puede modificar un pedacito de un objeto**. Si querés cambiar un byte de un archivo de 1 GB, tenés que subir el 1 GB de nuevo. Por eso S3 no sirve para nada que escriba de forma incremental.
