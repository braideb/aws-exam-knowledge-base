# Demostración: Container of cats (Docker en EC2)

🔗 <https://learn.cantrill.io/courses/1101194/lectures/36184903>

En esta demo se instala Docker a mano en una instancia EC2, se hace el **build** de una image ("container of cats", un web server con fotos de gatos), se ejecuta un container a partir de ella y, opcionalmente, se sube la image a **Docker Hub**. Es la misma image que después se despliega en ECS con Fargate ([[08.07 Demostración - Container of cats en Fargate|demo de Fargate]]).

### Comandos

```bash
# Install Docker Engine on EC2 Instance
sudo dnf install docker
sudo service docker start
sudo usermod -a -G docker ec2-user

# LOGOUT and login
sudo su - ec2-user

# Build Docker Image
cd container
docker build -t containerofcats .
docker images --filter reference=containerofcats

# Run Container from Image
docker run -t -i -p 80:80 containerofcats

# Upload Container to Dockerhub (optional)
docker login --username=YOUR_USER
docker images
docker tag IMAGEID YOUR_USER/containerofcats
docker push YOUR_USER/containerofcats:latest
```

### Qué hace cada bloque

| Bloque | Qué pasa |
|---|---|
| Install Docker Engine | Instala Docker con `dnf`, levanta el servicio y agrega a `ec2-user` al grupo `docker` para poder usarlo sin `sudo`. |
| Logout and login | El cambio de grupo recién aplica en una sesión nueva. |
| Build | `docker build -t containerofcats .` construye la image a partir del Dockerfile de la carpeta actual y le pone el nombre (tag) `containerofcats`. `docker images` confirma que existe. |
| Run | `docker run -p 80:80` arranca un container y mapea el **puerto 80 del host** al **puerto 80 del container** (el que expone el Dockerfile). |
| Upload (opcional) | Login en Docker Hub, `docker tag` con `usuario/repositorio` y `docker push` al registry. |

> [!note] Subir la image a ECR en lugar de Docker Hub
> Los comandos equivalentes (login con `aws ecr get-login-password`, tag con la URI del repository y push) están al final de [[08.08 Elastic Container Registry (ECR)#Cómo subir una image a ECR|Elastic Container Registry (ECR)]].
